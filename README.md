## Objetivo

Crear un repositorio local con Git, vincularlo con un repositorio público en GitHub y comprobar la sincronización en ambos sentidos mediante commits, `git push` y `git pull`.

## Archivos

- `README.md`: documentación de la práctica.
- `datos.txt`: archivo para comprobar cambios desde GitHub y desde la computadora.

## Inicio de la práctica

Creé esta carpeta, inicialicé el repositorio con `git init` y establecí `main` como rama principal con `git branch -M main`. Los archivos iniciales se registran desde la computadora. Completaré la explicación del procedimiento al terminar la sincronización.
